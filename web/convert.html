OpenAI Exit Kit GitHub

Free and open source. Nothing is uploaded.

OpenAI is shutting down Evals and stored prompts on 2026-11-30. Get your work out first.

Drop in an Evals export and this page writes a promptfoo project for each eval (config, tests, migration report). Drop in stored prompt objects and it writes TypeScript and Python functions. The conversion runs in your browser; the page is built so it cannot make network requests.

Source: OpenAI deprecations page. Check it yourself; dates can change.

1. Add your files

Drop files or a folder here eval.json, runs.json, *.output_items.jsonl, dataset *.jsonl, prompt object *.json, or plain .txt/.md prompts
