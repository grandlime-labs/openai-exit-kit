OpenAI is shutting down Evals and stored prompts on 2026-11-30. Get your work out first.

This tool turns an OpenAI Evals export into a promptfoo project for each eval (config, tests, graders, and a migration report), and turns stored prompt objects into plain TypeScript and Python functions.

Privacy: the converter runs fully in your browser. Your files are never uploaded. The converter page is built with a Content-Security-Policy of connect-src 'none', so the browser itself blocks network requests from that page.

Try it View on GitHub

Shutdown dates: OpenAI deprecations page (re-checked 2026-11-10). Check it yourself; dates can change. This project is not affiliated with OpenAI or promptfoo.

What it does

  • Reads eval definitions, run objects, output items, and dataset files.
  • Maps string_check, text_similarity, label_model, score_model, python, and multi graders to promptfoo assertions, and labels each mapping exact, approximate, or manual.
  • Turns stored prompt objects (versions and variables) into typed functions you can keep in git.
  • Also ships as a command-line tool, including a read-only exporter that only makes GET requests.

It does not call a model, compute scores, or migrate Agent Builder workflows. Manual graders are written as failing placeholders on purpose, so a result can never look green because a grader was skipped.
